# 🖤 NOIRVA – Social Media Platform

NOIRVA is a modern social media platform with a premium black-and-gold theme. Users can share posts, create stories, and connect with others.

## ✨ Features

* User Registration and Login
* Create Posts, Likes, and Comments
* Golden Moments – 24-hour Stories
* Gold Creator Score – Creator Rankings
* Noir Studio – Custom Post Design
* Responsive User Interface

## 🛠️ Technologies

* HTML, CSS, JavaScript
* Node.js, Express.js
* MongoDB

## 🚀 Installation

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure the `.env` file.
4. Start the server using `npm start`.
5. Open the application in your browser.
